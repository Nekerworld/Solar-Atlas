# 요구사항 추적과 셀프 체크리스트

필수 F3001~F3019와 NF3001~NF3007을 구현 대상으로 하고, 메인 Agent는 LangGraph 그래프(분석 → 확인 → 계획 → 실행 → 판정 → 재계획 루프 → 응답, `docs/AGENT_WORKFLOW.md`)로 만들었다. 대표 시나리오는 7건이다(`docs/TEST_REPORT.md` 2절). 심화는 **F3022(RAG 검색 Tool)만** 선택했다. F3020, F3021, F3023은 선택하지 않았다. 규칙만으로 판정하므로 이상 징후 진단(F3020)도 넣지 않았다.

제공받은 3일차 셀프 체크리스트 파일이 없어, 요구사항 정의서의 항목을 그대로 체크 항목으로 삼았다. "확인" 열은 실제로 돌려 본 근거이고, 못 돌린 것은 "미검증"으로 적었다. 근거 문서와 결과는 `docs/TEST_REPORT.md`, `docs/API_VALIDATION.md`에 있다.

## 필수 기능

| 항목 | 구현 | 확인 |
| --- | --- | --- |
| F3001 Tool 정의 | Tool 이름, 설명, 입력·출력 JSON Schema, external/local 구분, 실패 형식을 레지스트리에 둔다. 입력 명세와 함수 인자가 맞는지 테스트한다. 미등록 Tool은 예외 없이 실패한다. | pytest. `docs/TOOL_SPEC.md` |
| F3002 장소 검색 Tool | `search_places`. 날짜가 없으면 추정 시간창을 밝힌다. 지역은 비우면 검색하지 않는다. | 실호출 성공, 시나리오 S1~S4 |
| F3003 천문력 Tool | `get_ephemeris`. 좌표로 Horizons 고도·방위·태양 고도를 얻는다. 비면 판정하지 않는다. | 실호출 성공, 시나리오 S1~S4 |
| F3004 장소 상세 Tool | `get_place_details`. 이름, 주소, 지도 링크, 좌표. 없으면 `NO_RESULT`. | 실호출 성공 |
| F3005 요청 분석 | 기준, 선호, 제약과 빈 칸을 응답과 화면에 보여 준다. | 실제 GMS(`claude-haiku-5-5`)로 대표 문장을 실호출해 날짜, 시각, 장소, 의도를 확인. 시나리오 스크립트는 고정 분석 결과를 쓴다. |
| F3006 작업 계획 | 작업 순서를 보관한다. 사용법 질문은 계획을 건너뛴다. | S5. GMS 계획 실호출은 S1~S4에서 확인했다. 관측 도구 묶음을 항상 함께 실행하도록 고쳤다. |
| F3007 Tool 순차 호출 | 앞 결과의 식별자를 다음에 넘긴다. 하나가 실패해도 나머지를 계속한다. | S4 |
| F3008 결과 통합 | 측정값으로만 비교한다. 연속 구간의 경계를 확인된 천문력으로 말한다. 확인하지 못한 값은 `UNVERIFIED`. | S1, S4 |
| F3009 재계획 | 측정한 조건을 못 맞춘 후보만 있거나 장소 검색 결과가 없을 때만 재계획한다. 키 없음, 예보 범위 밖처럼 다시 해도 같은 오류는 재계획하지 않고 바로 안내한다. 상한 3. 같은 성공 입력은 재사용한다. | S2(1회 성공), S3(3회 중단), S4·S7(재계획 없이 안내), pytest |
| F3010 컨텍스트 관리 | 바꾼 조건만 갱신한다. 외부 원문 응답은 캐시에만 둔다. | pytest |
| F3011 최종 응답 | 추천, 보조 정보, 기준, 근거, 제외 사유. 불충족 이유는 조건별로 기준값과 관측된 최선값을 보여 준다. | S1, S3 |
| F3012 이벤트 | 단계 진입·종료, **Tool 호출 요청·완료(이름, 소요시간, 성공 여부)**, Tool 재사용, 의도와 이유, 계획 주체, 재계획 이유와 재계획하지 않은 이유(`replan_skipped`). | pytest, `docs/samples/execution_log_sample.json` |
| F3013 로깅 Agent | 이벤트를 구독해 저장한다. conversation id로 세션을 나눈다. LLM을 부르지 않는다. | pytest |
| F3014 로그 조회 | 목록, 순서 조회, 삭제. 수정 API는 없다. | pytest |
| F3015 계획 저장 | 천체, 장소, 시작, 종료, 생성 시각. 겹침은 경고한다. | pytest |
| F3016 계획 관리 | 수정, 삭제 후 목록을 다시 그린다. 재검사가 저장을 막지 않는다. | pytest, 화면 |
| F3017 FastAPI | 대화, 계획, 로그 경로가 다르다. 요청과 응답을 Pydantic 모델(`app/schemas.py`)로 정의하고 모든 JSON 경로에 `response_model`을 붙였다. `/docs` 제공. | pytest(OpenAPI 응답 스키마 확인), `docs/openapi.json` |
| F3018 Vue 화면 | 대화 화면과 계획 관리 화면. | Playwright 3개 |
| F3019 진행 표시 | 단계 진행 순서, Tool 호출 이력(이름, 성공·실패, 소요시간, 재사용), 재계획 지점, 실패 안내. 저장된 로그로 같은 순서를 다시 읽는다. | Playwright, vitest |

## 범위에서 뺀 것과 열린 것

- **Google Routes(`get_route`)**: 200 응답이 비어 있어 제외했다. `PLANNER_ROUTES_ENABLED=false`가 기본이며 Tool 목록과 계획에 나오지 않는다. 이동시간 제한이 있는 요청은 "확인하지 못했다"고 밝히고 값을 추정하지 않는다. 코드는 남겨 두었다.
- **GMS 실호출**: LLM(`claude-haiku-5-5`)의 의도 분석, 작업 계획, 답변 생성은 2026-11-20 실호출로 검증했다(OpenAI 경로 429로 Claude Haiku로 교체한 뒤 의도 분석·작업 계획·2차 답변 생성 각 1건 확인). 질문 임베딩(`text-embedding-3-large`)은 OpenAI 조직 한도(HTTP 429)로 미검증이다.
- **외부 API 3종의 키 조건**: Horizons와 Open-Meteo는 키가 없다. "키 발급" 조건을 어떻게 적용하는지는 강사에게 확인해야 한다. Google Places는 키로 실호출했다.
