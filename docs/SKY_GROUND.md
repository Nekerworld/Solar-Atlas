# 지상 모드 천구 (천구 엔진)

지상 모드의 하늘은 천구 엔진의 천구 엔진이 그린다.
프론트엔드는 Vue 하나이고, 천구 엔진의 React 셸은 쓰지 않는다.

## 구조

| 위치 | 역할 |
| --- | --- |
| `frontend/sky/entry.js` | 천구 엔진의 메인 클래스를 React 없이 띄우는 진입점. `postMessage`로만 제어된다. |
| `frontend/sky/ground.js` | 땅: 지구 표면 지도를 평균색 한 점으로 바꾸고, 발밑에 도시 보도블록 원판을 깐다. |
| `frontend/sky/horizon.js` | 산맥 지평선: 노이즈로 높이를 정한 산줄기 세 겹을 땅 둘레에 세운다. |
| `frontend/sky/koNames.js` | 별자리·별·천체 이름표를 한국어로 바꾸는 표와 규칙. |
| `frontend/sky/bundle.mjs` | 위 진입점과 천구 엔진 소스를 esbuild로 묶어 `frontend/public/sky/`에 둔다(데이터 포함, 커밋하지 않음). 천구 엔진 소스는 고치지 않고, 번들할 때만 두 곳을 바꾼다(아래 "땅"). |
| `frontend/src/scene/atlasSky.js` | Vue 쪽 어댑터. iframe 생성·로딩·보이기/숨기기·장소/시각/시선 전달. |
| `frontend/src/views/SolarView.vue` | 맨 처음 로딩에서 `preloadAtlas()`를 함께 수행하고, 둘 다 끝나야 로딩 화면을 닫는다. |
| `frontend/src/views/GroundView.vue` | 조작부(시각·위치·장소 검색)만 Vue로 두고, 하늘은 iframe 위에서 보인다. |

별도 번들·iframe으로 둔 이유: 앱의 three(0.140)와 천구 엔진의 three(0.171)가 섞이지 않고, 천구 엔진의 전역 상태
(`window.c`, 주소 조각, 키 입력)가 앱을 건드리지 않는다.

## 로딩

Solar Atlas를 처음 열 때 iframe을 숨긴 채 올려 엔진·별 목록·행성 위치 계산·대기 계산을 모두 끝낸다.
로딩 화면은 "지상에서 올려다볼 밤하늘을 펼치고 있어요" 단계를 포함하며, 지구 위에서 첫 화면이 그려진 뒤에 닫힌다.
이후 지상 모드는 iframe을 보여 주기만 하고, 다른 화면에서는 그리기를 멈춘다.
번들이 없거나 실패하면(5초 안에 첫 신호가 없음 등) 앱은 그대로 열리고, 지상 모드에서 안내 문구만 보인다.

## 준비

1. 천구 엔진을 이 저장소와 나란히(`../web`) clone하고, 그 폴더에서 `yarn install`을 한다. 경로가 다르면 `SKY_ENGINE_SRC`로 지정한다.
2. `cd frontend && npm run build:sky`
3. 이후 `npm run dev`/`npm run build`는 `public/sky/`를 그대로 서빙·복사한다.

## 표현 범위

- 별·행성·태양·달·대기·별자리선은 천구 엔진의 계산(VSOP87, 별 목록)이다. 땅은 지표 지도(약 80MB)를 쓰지 않고 아래 "땅"처럼 그린다.
- 대상 천체의 고도·날씨는 기존대로 Horizons·예보를 쓰며, 최종 적합성은 Horizons가 판정한다.
- 궤도선은 기본으로 끄고, 라그랑주점·궤도 영역·태양풍 선 같은 확장선은 없앴다(아래 "소천체와 황도, 궤도 정책"). 드래그로 시선을 돌리고, 지평선은 항상 수평으로 유지한다. 휠로 확대·축소한다.

## 내 위치·시각, 낮밤, 진입과 선택 (플래너 연결)

- **진입**: 태양계 화면 왼쪽 아래 로켓 아이콘 "지상 관측" 버튼이 `openObservation("Earth")`로 지상 모드에 들어간다. 태양계 화면의 천체별 "이 천체 관측하기" 버튼은 없앴고, 각 천체는 지상 모드에서 고른다. 관측 플래너 머리말에는 "태양계로"와 "플라네타리움으로"가 있다.
- **내 위치·시각**: `data/userLocation.js`가 브라우저 위치 정보(Geolocation)를 요청한다. 허용되면 그 좌표와 현재 시각으로 시작하고, 거부·실패하면 서울을 기본값으로 쓰되 화면에 "내 위치 아님"을 밝힌다. 위치는 서버로 보내지 않고 화면 안에서만 쓴다. 관측 계획에서 들어오면 계획의 장소·시각을 쓴다.
- **낮밤 시뮬레이션**: 천구 엔진이 시각과 좌표로 태양 위치와 대기 산란을 그리므로 하늘이 밝아지고 어두워진다. 하루 시간 슬라이더와 속도(실시간·1분/초·10분/초·1시간/초)로 조절하고, 태양 고도로 낮·박명·밤 배지를 보여 준다. 노출은 천구 엔진 자동 노출(측광)을 따르되, 태양이 화면에서 커져도 하늘·땅이 어두워지지 않도록 iframe이 측광 입력에서 태양 원반을 빼고 목표 게인을 1 아래로 내리지 않게 한다(`entry.js` `keepDaylightExposure`). 태양은 흰 원반으로 날아간다. 밤의 노출은 바뀌지 않는다.
- **천체 선택**: iframe이 `atlas:pick`(이름표 종류·이름·화면 좌표)을 보내면 지상 화면이 카드를 띄운다. 행성·달이면 "이 천체 관측하기"가 나오고 누르면 기존 관측 플래너 창으로 넘어간다. 별·별자리·태양·기타 천체는 사유를 보여 준다. 더블클릭 이동은 지상에 머물도록 막아 두었다.
- **관측 일정**: 관측 플래너의 대상 천체 아래 "내 위치에서 보이는 일정"(앞으로 7일)을 보여 준다(`utils/visibility.js`, astronomy-engine, 10분 간격). 계획을 만들면 Horizons와 예보로 다시 판정하며, 일정에서 "이 시간으로 계획 요청 쓰기"와 "이 시간 천구에서 보기"로 이어진다.

## 태양계와 같은 조작 UI (천체 탐색·검색, 속도, 표시 토글)

- **천체 탐색·검색**(`SkyPicker.vue`, 위쪽 가운데): 태양계 `BodyPicker`와 같은 모양이다. 태양·달 버튼, 행성(명왕성 포함)·별·별자리 분류, 전체 검색(한국어·영어·별칭)이 있고, 고르면 그 방향으로 시선을 돌린다. 지평선 아래면 안내 문구와 함께 지평선 가까이를 보여 준다. 목록은 `data/skyCatalog.js`다: 태양·달·행성은 astronomy-engine, 별(밝은 별 약 30개와 북극성)과 별자리(대표 30여 개의 중심)는 J2000 좌표로 방향만 구한다. 위성·왜소행성·소행성·혜성·탐사선은 JPL Horizons 위치가 도착하면 분류로 추가된다(아래 "소천체와 황도, 궤도 정책").
- **속도와 표시**(`SkyControls.vue`, 오른쪽 위): 태양계 `SettingsPanel`과 같은 모양(−/+, 슬라이더, 상태 표시, 스페이스바 일시정지)이다. 속도는 일시정지·실시간·1분/초·10분/초·1시간/초·1일/초 단계(`utils/skySpeed.js`)이고, 기본은 일시정지다. 토글은 라벨(행성·별 이름표)·궤도·별자리선·구름·적도 좌표격자와 리셋이다. 격자를 켜면 IAU 별자리 경계선(`frontend/sky/constellationBounds.js`, 데이터는 d3-celestial의 BSD-3-Clause 자료)이 옅은 푸른 회색으로 함께 보인다. 별자리 이름표에 마우스를 올리면 그 별자리의 그림이 선 뒤에 희미하게 뜬다(`frontend/sky/constellationArt.js`, 그림은 `frontend/public/constellation-art/`의 Stellarium Free Art License 자료, 출처는 그 폴더의 `NOTICE.md`). 기본값은 라벨·별자리·구름 켬, 궤도·격자 끔이며 태양계 화면과 상태를 공유하지 않는다.
- **조건 카드**(왼쪽 위): 이동 버튼, 시선, 태양 고도 배지, 하루 시간 슬라이더, 접이식 관측 조건(시각·위도·경도·고도·장소)이 있다.
- iframe 규약: 부모 → `atlas:settings`(천구 엔진 설정 문자 p·l·o·a·i·e·x), `atlas:view`(장소·시각·시선), `atlas:aim`(시선만), `atlas:clock`(시간 배율). iframe → `atlas:gaze`(시선, 프레임마다), `atlas:time`(천구 시각, 초당 5번 안팎), `atlas:pick`, `atlas:key`(스페이스바). 천구 안의 글자 단축키는 부모의 설정과 어긋나므로 막는다. 라벨을 끄면 이름표 선택·강조도 되지 않는다.

## 시간 흐름, 시선, 선택 강조, 한국어 이름, 땅

- **시간 흐름**: 시간은 천구(iframe)가 천구 엔진의 `Time`(배율·일시정지)으로 프레임마다 직접 흘린다. 앱이 100ms마다 시각을 보내 흘리면 메시지와 화면 갱신이 천구의 그리기와 같은 스레드에서 끼어들어 프레임이 끊겼다. 앱은 배율만 알려 주고, 천구가 알려 주는 시각을 왼쪽 위 카드에 초 단위(한국 표준시)로 보여 준다. 폼의 시각(분 단위)과 그에 딸린 계산은 흐르는 동안 초당 한 번만 고친다.
- **빠른 시간 최적화**: 배율이 초당 10분 이상이면 (1) 하루마다 NASA 구름 지도를 새로 받아 합치는 일을 쉬고 (2) 구름 부피를 낮은 해상도(최대 1/4)로 그린다. 지표의 월별 색 지도는 땅을 한 색으로 쓰므로 아예 받지 않는다. 느려지면 원래대로 돌아온다. 멈추면 그 순간의 시각을 곧바로 받아 대상 고도·날씨를 다시 확인한다.
- **시선**: 시선(방위·고도) 표시는 프레임마다 갱신한다. 탐색·"시선 다시 맞추기"로 시선을 돌릴 때는 처음엔 빠르게 끝에서 천천히(0.25~0.7초) 움직이고, 끌기·방향키를 시작하면 멈춘다.
- **선택 강조**: 이름표 위에 마우스를 올리면 커서가 손 모양으로 바뀌고 이름표에 테두리가 생긴다. 선택(클릭)과 같은 판정을 쓴다. 글자 맨 위가 그 방위의 지평선·산맥보다 낮아 이름표 전체가 가려지면 고르지 않는다. 글자 일부만 산마루 위로 보이면 그대로 고를 수 있다.
- **한국어 이름**: 천구 엔진의 이름표는 영어뿐이라, 이름표가 캔버스에 글자를 그리기 전에 `koNames.js`의 표로 바꾼다. 88개 별자리, 고유 이름 별(약 330개, 소리 나는 대로), "별자리+그리스 문자/번호" 형태의 별(예: 물고기자리 τ), 글리제 별, 천체(행성·위성·탐사선)를 다룬다. 표에 없는 카탈로그 번호(GJ·HIP·소행성 번호 등)는 그대로 둔다. 선택 카드도 같은 한국어 이름을 쓴다.
- **땅**: 발밑에 관측 지점에 접하는 평평한 원판(반지름 30km)을 깔고 도시 보도블록 무늬(`frontend/public/assets/city_pavement.jpg`, 한 장 0.8m를 반복)를 입힌다. 원본 사진(헤링본 보도블록)을 조명 편차를 없애고 2×2 주기로 잘라 가장자리를 이웃 픽셀과 섞어 이음매 없는 256px 타일로 가공해 다른 천체 텍스처와 같은 `public/assets` 폴더에 두며, iframe이 부팅할 때 내려받는다. 몇 미터 크기의 얼룩(물기·때)을 셰이더 잡음으로 얹어 반복을 가리고, 6m부터 1.5km 사이에서 평균색으로 흐려져 먼 땅과 이어진다. 빛은 장면의 태양 조명을 그대로 받고, 해가 낮거나 진 때에도 땅이 알아볼 만큼 하늘빛·별빛을 받게 노출로 나눠 보탠다. 눈높이 2m에서 발밑이 보이도록 번들할 때만 천구 엔진의 가까운 면을 100m에서 0.3m로 줄이고(`zoom.js`), 그 때문에 아주 먼 별의 깊이값이 1로 둥글려져 이름표 위치 계산에서 빠지는 것을 막으려고 `labelPick.js`의 한 비교식을 고친다. 이름표 글자 크기가 거리·밝기에 따라 달라지지 않게 `labelStyle.js`의 한 식도 고쳐 늘 같은 크기로 그린다. 세 고침이 적용되지 않으면 번들이 실패한다.
- **산맥 지평선**(`horizon.js`): 땅 원판 둘레 9.5km·19km·29km에 산줄기를 세 겹으로 세운다. 높이는 노이즈(값 잡음 9겹, 일부는 뾰족하게 접음)로 정하고 줄기마다 백분위로 늘려 맞추며, 장소(위도·경도)마다 모양이 다르다. 멀수록 높고 하늘빛에 흐리다. 벽의 밑동은 땅의 평균색·법선과 같아 평지로 이어지고, 산마루만 비탈에 맞춘 법선과 숲·바위 색을 가진다. 땅과 같은 태양 조명·하늘빛을 쓴다.
- **텍스처 출처**: `city_pavement.jpg`는 Dreamstime의 보도블록 사진(작가 JaCrispy, https://thumbs.dreamstime.com/b/concrete-tile-texture-city-pavement-background-abstract-stone-brick-pattern-street-sidewalk-151573872.jpg)을 가공한 것이다. 상업적 이용 조건은 Dreamstime 라이선스를 따로 확인해야 한다.

## 소천체와 황도, 궤도 정책

- **표시 대상**: 태양계 화면의 모든 천체 중 JPL Horizons에서 지구 중심 적경·적위를 받을 수 있는 것을 천구에도 그린다. 행성·달·태양과 천구 엔진에 내장된 천체(제임스 웹 등)는 천구 엔진이 그대로 그리고, 나머지(위성·왜소행성·소행성·혜성·탐사선, `planner_backend/app/sky_bodies.py`의 `BODIES`)는 iframe이 하늘 위의 점과 한국어 이름으로 얹는다(`frontend/sky/skyBodies.js`). 모행성 가까이 있는 위성은 시야가 충분히 좁을 때만 보인다. 라벨 토글은 점·이름에도 적용된다.
- **제외**: 지구 궤도를 도는 ISS·톈궁·허블(지구 중심 위치가 Horizons에 없거나 의미가 없음), Horizons가 위치를 주지 않는 다프니스·히이아카·나마카, 라그랑주점(sun-earth L4 등)·궤도 영역·ed138·태양풍 선. 별자리는 남긴다.
- **위치 공급**: `GET /api/sky/bodies?start&hours=720&step_minutes=120`가 30일 구간을 2시간 간격(361개)으로 돌려준다. 프런트(`src/scene/skyBodies.js`)가 현재 시각 주변을 받아 iframe(`atlas:bodies`)에 보내고, 구간을 벗어나면 다시 받는다. iframe은 Catmull-Rom으로 사이 값을 구한다(`src/utils/ephemerisInterp.js`, 앱과 iframe이 공유). J2000 좌표를 날짜의 장면 좌표로 옮기고 관측자 지평 좌표로 바꿀 때는 먼저 of-date 적도 좌표로 세차 보정한다. 첫 호출은 Horizons를 천체마다 부르므로 약 15초 걸리고, 이후는 캐시한다. 못 받은 천체는 `unavailable`에 이유와 함께 담고 값을 만들지 않는다.
- **황도**: 궤도 토글을 켜면 황도선(금색, 3.2px)을 하늘 한 바퀴로 항상 보여 준다. 예전의 점선은 지구 궤도를 지구에서 본 모습(황도의 절반)이라 이것으로 대체했다.
- **궤도 정책**: 궤도 토글을 켜도 태양을 뺀 천체의 궤도는 그 천체를 클릭했을 때만 그 천체 것만 보인다(빈 곳을 누르면 사라진다). 천구 엔진 천체는 자기 궤도 노드를 보이고(파란색), 소천체는 `GET /api/sky/orbit?body&epoch`의 케플러 타원(Horizons ELEMENTS, 황도 J2000, 위성은 모행성 중심)을 받아 그린다. 쌍곡선·탐사선처럼 닫힌 궤도가 없으면 `NO_CLOSED_ORBIT`로 궤도선을 그리지 않는다. 선택 카드에는 지구와의 거리와 겉보기 등급(Horizons)이 나온다.
- **휠 확대·축소**: iframe이 휠을 가로채 시야각(0.5°~100°)을 지수로 조절한다.
- **표시 토글**: 태양계 화면과 같은 규칙으로, 탐색 드롭다운의 눈 아이콘으로 천체를 하나씩, "표시" 스위치(켬·일부·끔 세 상태)로 분류를 통째로 켜고 끈다. 대상은 행성·별자리·위성·왜소행성·소행성·혜성·탐사선이고, 태양·달과 별(밝은 별)은 별 타일 안에 있어 하나씩 숨길 수 없으므로 토글에서 뺐다. 분류를 끄면 천체가 모두 숨고, 숨긴 천체를 이름이나 검색으로 고르면 그 천체만 켜진 채 시선이 움직인다(분류의 나머지는 계속 숨김). 숨긴 분류의 단추는 흐려지고, 숨긴 천체의 정보 카드는 닫힌다. 천구 오른쪽 조작부의 "리셋"이 표시를 처음 상태(태양·달·행성·별·별자리만 보이고, 라벨·별자리선·구름은 켜짐, 궤도·격자는 꺼짐)로 되돌린다. 상태는 `src/scene/skyVisibility.js`가 갖고(`isSkyObjectVisible`, `toggleSkyObject`, `setSkyCategory`), `atlas:visibility`로 iframe에 보낸다. iframe(`skyBodies.js`의 `setHidden`)은 행성은 본체·이름표가 든 `new planet` 노드를 가리고(위성은 그대로), 소천체는 점·이름표를 가리며, 별자리는 한 덩어리 선 인스턴스에서 숨긴 별자리의 선분을 빼고 다시 채워 `instanceCount`를 줄이고 이름표를 끈다. 별자리 선분 수가 엔진 값과 맞지 않으면 선은 건드리지 않는다. 탐색 목록에 없는 별자리는 분류 스위치만 따른다.
- iframe 규약 추가: 부모 → `atlas:bodies`, `atlas:orbit`, `atlas:visibility`(`{categories, ids}`). iframe → `atlas:need-orbit`(소천체 선택 시 궤도 요청).
